# Week 33 practical task

## Brief
Build a command-line prototype with clear validation and a fallback when no result is relevant

## Small deliverable
Create the smallest useful artifact that answers one clear question: a script, query set, chart, model comparison, API prototype, test suite, or written interview/portfolio worksheet as appropriate for the week.

## Acceptance checklist
- [ ] State the problem and intended audience in plain language.
- [ ] Follow the week's learning plan and keep the solution small enough to explain.
- [ ] Use synthetic or appropriately licensed non-sensitive inputs; cite any public source.
- [ ] Check one normal case and at least one limitation, edge case, or failure mode.
- [ ] Record what worked, what did not, and what you would practise next.

Do not claim model quality, business impact, placement readiness, or mastery without evidence. Week 24 uses synthetic student records and is not suitable for real student decisions.
