# Week 39 learning plan

Aim for five sessions of roughly 45-90 minutes. Each day: spend a few minutes recalling yesterday's ideas, study one small section, do the task below, and write one question. Reduce the scope if a session runs long.

## Day 1: Component state

- Read the Week README and the first linked section. Make a five-line glossary; do not code from memory yet.

## Day 2: forms

- Recreate a tiny example by hand, then in code or a query. Record the input, output, and why they match.

## Day 3: fetch

- Complete Exercise 1 independently. Try one normal case and one boundary or invalid case.

## Day 4: loading/error states

- Complete Exercise 2 or a project milestone. Explain each transformation/decision in comments or notes.

## Day 5: API contract; CORS; environment variables without secrets

- Finish the weekly mini-project, review [revision.md](revision.md), and update [progress.md](progress.md). Note one unresolved question.

## Flexibility

If the fifth day is not enough, carry the project into another session. Understanding the prerequisite and checking your own result matters more than keeping pace with a calendar.
